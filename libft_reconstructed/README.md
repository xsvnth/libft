Description

libft is our very first individual C library project at 42. The goal is to recode a set of standard C library functions, along with additional utility functions and linked list manipulations, to build a reusable static library (libft.a) for future projects.
Instructions

    Compilation: Run make (or make all) to compile the library and generate libft.a.

    Cleaning Object Files: Run make clean.

    Full Cleanup (Objects + Library): Run make fclean.

    Recompilation: Run make re.

Detailed Library Description

The library includes:

    Part 1 (Libc Functions): Reimplementations of standard C library functions (e.g., ft_strlen, ft_memcpy, ft_strlcpy, ft_atoi, etc.).

    Part 2 (Additional Functions): Non-standard or custom helper functions for string handling and input/output (e.g., ft_substr, ft_strjoin, ft_split, ft_itoa, ft_putendl_fd, etc.).

    Part 3 (Linked Lists): Functions to manage and manipulate linked list nodes (e.g., ft_lstnew, ft_lstadd_front, ft_lstclear, ft_lstmap, etc.).

Resources & AI Usage

    Resources: Standard C man pages, C programming references, and peer discussions.

    AI Usage: AI was used as a learning and debugging assistant to understand complex edge cases, review logical structures, and clarify documentation concepts during the development process.
